# Fotografías de Cultura Gauchesca

Esta carpeta recibe **12 imágenes WebP** del glosario del mate y la campaña rioplatense.

Para subirlas: entrar en esta carpeta, pulsar **Add file → Upload files**, arrastrar los 12 archivos `.webp` descomprimidos y confirmar **Commit changes**.

Los nombres exactos, los textos ALT y el estado de derechos están listados en `documentacion/IMAGENES-CULTURA-GAUCHESCA-SEO-INVENTARIO.md`.

La guía `src/pages/cultura-gauchesca/index.astro` detecta estas imágenes al generar el sitio. Hasta recibirlas, muestra recuadros de respaldo. Son **recreaciones visuales modernas**, no fotografías históricas.
