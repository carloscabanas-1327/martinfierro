**Alcance de estos hallazgos:** extracción de href literales del código Astro. Algunas páginas usan componentes o expresiones generadas dinámicamente, de modo que ausencia en esta tabla NO demuestra ausencia en el HTML final. Una mención textual de «canto» tampoco valida por sí sola qué canto deba enlazarse.

## Problema estructural
El usuario recorre revista -> índice general -> obra -> parte -> canto en vez de revista -> canto pertinente. La edición inglesa dispone de un índice y herramientas de búsqueda más desarrollados, pero no debe copiarse ciegamente el número de enlaces del menú inglés.

## Script automatizado incorporado
`scripts/auditar-grafo-es.py` lee archivos HTML ya compilados desde `dist/`, identifica rutas españolas, registra enlaces entrantes, enlaces contextuales frente a navegación/pie, URLs potencialmente rotas, páginas inalcanzables desde portada y candidatos que mencionan cantos pero carecen de enlaces directos. Usa únicamente Python estándar y no modifica la aplicación.
Ejecución propuesta: `npm run build && python3 scripts/auditar-grafo-es.py dist auditoria-grafo-es.json`.
El script informa candidatos, no dictámenes editoriales: debe revisarse individualmente cada enlace sugerido. No ejecuta JavaScript ni detecta la interacción de enlaces generados en cliente.

## Páginas huérfanas
**No declaradas exhaustivamente aún.** Para emitir lista confirmada es imprescindible analizar el HTML completo de `dist/` resultante de este commit, no únicamente archivos de origen. Diferenciar:
- sin enlace entrante en páginas ES;
- accesible solo desde menús o pie;
- sin enlace contextual en cuerpo;
- no alcanzable desde portada.
Estas categorías no son equivalentes.
